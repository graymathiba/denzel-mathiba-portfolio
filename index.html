03 Selected projects

GraySale ERP

Retail POS · inventory · double-entry accounting · Windows + LAN

In production

A local-first retail platform built and maintained as sole developer. It covers the full commercial loop — catalog and price tiers, FEFO batches, UoM conversion, bundles, stock ledger, POS with refunds and layaway, purchasing, AR/AP ledgers, and balanced-only double-entry journals with trial balance, P&L, balance sheet and bank reconciliation.

  • 148 REST endpoints across 13 route modules; 55 backend modules; 63-module React 18 admin SPA.
  • 41-table normalised SQLite schema with WAL journaling, foreign keys and 12 versioned migrations.
  • Offline-first sync: client-generated UUIDs on a unique index, idempotent replay, server re-pricing with price-drift reporting, capped batches and per-sale failure isolation.
  • ZIMRA FDMS fiscalisation with ECDSA P-256 device keys, hand-built PKCS#10 CSR, offline simulator and fiscal queue.
  • Security: scrypt hashing, SHA-256 session tokens (12h TTL, single session), login rate limiting, role-to-capability matrix, tenant isolation, audit log, hardened headers.
  • Browser-side ESC/POS printing (Web Serial → WebUSB → print fallback, 80/58mm, cash-drawer pulse), WhatsApp/email receipts, A4 invoices and quotes.
  • Ops: scheduled VACUUM INTO backups with rotation and one-click restore, 29 test files, GitHub Actions CI, Windows installer with WebView2 host.
